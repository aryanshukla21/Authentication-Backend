# Authentication Backend Project

This project is designed as an authentication backend with distinct folders for the frontend and backend.

## Project Structure

- **frontend/**: Contains all the files necessary for the frontend application.
- **backend/**: Contains the server-side code used for authentication processes.

## Usage

1. Clone the repository.
2. Navigate to each folder to set up the frontend and backend applications separately.
3. Follow the instructions in each folder's README for installation and configurations.

## Features

- User Registration
- User Login
- Password Recovery
- Token-based Authentication

## Conclusion

This authentication backend provides a solid foundation for managing user authentication in web applications.
